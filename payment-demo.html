🔐 Demo Details

This demo focuses on provider link generation and client-side totals. For production usage consider the notes below.

ℹ️ Demo Mode: This is a demonstration implementation. In production, you may want to:
  • Replace placeholder provider handles/links with your real accounts
  • Use server-side flows for providers that require it (for example, Stripe Checkout sessions)
  • Implement server-side verification if using on-chain cryptocurrency payments

📱 How It Works

  1. User selects a service (House Sitting, Drop In Visit, etc.)
  2. Payment amount is automatically calculated
  3. Provider link is generated with the payment details
  4. User follows the provider link to complete payment (opens in new tab)
  5. User sends payment to the displayed address
  6. System monitors blockchain for payment confirmation
  7. Payment status updates in real-time

🛠️ Technical Stack

  • Provider Links - Venmo, PayPal.me, Stripe (link generation)
  • Clipboard API - For copy functionality
  • CSS3 - Modern responsive design
  • Vanilla JavaScript - No framework dependencies

⚙️ Configuration

To use this in production, update the configuration in payment-script.js:

const PAYMENT_CONFIG = { // Replace with your actual Bitcoin address defaultAddress: '1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa', // Add your payment server endpoint paymentServer: 'https://your-server.com/api/payment', // Payment status check interval (ms) statusCheckInterval: 5000 };
⚠️ Security Note: Always validate payments server-side and never trust client-side payment confirmations alone. Implement proper webhook handlers and monitor the blockchain directly.
